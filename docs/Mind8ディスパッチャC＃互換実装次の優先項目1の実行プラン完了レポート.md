# Mind8ディスパッチャ C#互換実装 次の優先項目1の完了レポート

## 結果

通常ユーザーカーネルのC関数テーブル `mind8kernel/c_words.tbl` と、C#の `SetupCsFunctions()` を番号・関数名で照合しました。C版とC#版の間にあった `0x0061` の誤割当てを修正し、差分を実装状況文書へ記録しました。

## 実施内容

- C版テーブル743件（`0x0010`～`0x02F6`）と、C#の有効登録179件（`0x0010`～`0x026D`）を照合しました。
- C#登録のみの番号は0件、C・C#各テーブル内の重複番号も0件でした。
- C版関数名との不一致は当初 `0x0061` の1件でした。C版 `c_words.tbl` では `0x0060` と `0x0061` が `zzPopMemory`、`0x0062` が `zzPopMemoryWithResult` です。`compword.c` の処理本体も確認し、`0x0061` を `ZzPopMemory` へ修正しました。
- 修正後は関数名不一致、C#だけの番号、数値インデックス重複がすべて0件です。
- C版の同一関数エイリアス11組を確認し、C#側では対応済み4組、未登録の7組を記録しました。
- `tools/compare-c-function-table.js` を追加し、番号不一致・C#のみの番号・重複を検査できるようにしました。既定実行はC#側の対応整合性を検査し、`--strict` はC版に対する未登録番号も失敗として扱います。
- `docs/Mind8ディスパッチャC＃互換実装の実装状況.md` に全未登録範囲、エイリアス、修正内容、照合スクリプトの実行方法を反映しました。
