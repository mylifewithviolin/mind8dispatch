# Remind8Codeデバッグ連携PoC

通常の `Dispatcher.Main` の実行経路に、次の任意の連携機能を追加した。

- `BeforeInstruction`: 命令フェッチ前の安全な境界で実行されるコールバック。
- `DebugInstructionOffset`: 次の命令のMCO先頭からのバイト位置。
- `CaptureSnapshot`: データ／リターンスタック（トップが先頭）とデータ領域をコピーして取得する。
- `TraceEnabled`: 既定値true。従来の標準エラートレースを維持する。Remind8Codeの専用ホストのみfalseを指定する。

コールバック内で待機することで、実際の同じディスパッチャをステップ実行する。
スナップショットは停止境界またはMainの終了後、実行スレッドと競合しない時点で取得する。
このAPI自体は並行実行中の外部スレッドからの安全な読み出しを保証しない。
制御通信、停止要求、UI表示、ソースマップの管理はRemind8Code側の責務である。

最小変数PoCで使用する `ZzReadLvar` は、同一の下位32bitを二度積んでいた箇所を
実際の8バイト値の下位32bit・上位32bitへ修正した。
それ以外の既存命令実装やCLIの既定動作は変更しない。

配布や互換性の対象は既存と同じconsole ABIであり、完全なMindデバッガやサンドボックスではない。
